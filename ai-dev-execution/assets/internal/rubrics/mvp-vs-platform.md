# MVP vs Platform Rubric

visibility: internal_only

| Question | MVP only | Platform signal |
|---|---|---|
| 같은 구조를 다른 고객에게 재사용할가? | no | yes |
| 콘텐츠/문항/문구가 바뀌는가? | no | yes |
| 관리자 설정이 필요한가? | no | yes |
| 기관/세션이 여러 개인가? | no | yes |
| CSV/리포트가 반복되는가? | no | yes |
| 개인정보 정책이 고객별로 바뀌는가? | no | yes |

3개 이상 Platform signal이면 템플릿/세션/설정 분리 구조로 설계한다.
