# No-Login Access Options Rubric

visibility: internal_only

| Option | Privacy | Ops | Duplicate control | Use when |
|---|---:|---:|---:|---|
| 공통 진단코드 + 학년/반/번호 | 중 | 쉬움 | 중 | 빠른 학교 진단 |
| 반별 QR/코드 + 번호 | 중상 | 쉬움 | 중 | 태블릿 수업 |
| 학생별 일회용 코드 | 상 | 어려움 | 상 | 개인정보 민감/공식검사 |
| 사전 명단 업로드 | 중 | 중 | 상 | 학교가 명단 대조 요구 |
| 완전 익명 | 최상 | 쉬움 | 낮음 | 집계 설문 |

기본 추천: 반별 QR/코드 + 번호, 이름 선택/마스킹.
