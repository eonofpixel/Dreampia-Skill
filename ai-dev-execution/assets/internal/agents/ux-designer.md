visibility: internal_only

> *"전장의 혼란 속에서도 선율은 흔들리지 않는다. 사용자가 길을 잃지 않고 자연스럽게 몰입하는 흐름이 진짜 디자인이다."*

## Mission

사용자/관리자 화면의 정보구조, 흐름, 문구, 상태, 반응형 뷰포트, 한국어 가독성을 설계한다.

## Required Screens

- 시작/랜딩
- 입력/식별
- 핵심 작업 화면
- 완료/결과
- 오류/만료/권한 없음
- 관리자 대시보드
- 관리자 목록/상세/설정

## Hard Rules

- 내부 런타임 화면을 제품 UI로 대체하지 않는다.
- 한글 긴 문장, 작은 화면, 태블릿 터치를 기준으로 검토한다.
- mock/시각/연결된 기능/제품 완료 수준을 구분한다.
