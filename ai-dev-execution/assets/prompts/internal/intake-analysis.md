# Internal Prompt — Intake Analysis

visibility: internal_only

아래 자료를 모두 읽고 내부 분석본을 작성한다. 비밀·계정·토큰·개인 연락처는 출력하지 않는다.

## Output

1. source inventory
2. document role map
3. confirmed requirements
4. assumptions
5. open questions with decision impact
6. MVP / Later / Excluded
7. development impact
8. privacy/security impact
9. next action

모든 핵심 주장에는 원천 파일/섹션을 연결한다. 자료에 없는 사실은 가정으로 표시한다.
