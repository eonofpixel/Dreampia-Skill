# 간편 프로젝트

## 현재 명세
- 목적 / 첫 사용자 / 실행 모드 / 허용 범위 / 제외 / 종료 조건:
- 환경·런타임 / 기존 변경 보존 / 권한·비용 경계:
- R1: 관찰 가능한 정상·거부·경계 인수 조건, 출처·결정 근거
- 계약·불변식·적용하지 않는 위험(이유):

## 작업과 테스트
| 요구 | 작업 | 선행 | 변경 파일 | 테스트 ID / 명령 | 기대 결과 |
|---|---|---|---|---|---|
| R1 | T1 | 없음 | 실제 경로 | C1 / 실제 명령 | 관찰 가능한 결과 |

## 증거와 재개
- 현재 소스 기준점 / 실제 명령 / UTC 시각 / 환경 / PASS·FAIL·NOT_RUN / 로그 경로:
- Red 이유 / Green / Refactor / 구현 리뷰 / UI 리뷰 또는 미적용 이유:
- 작업 상태 / 중단 원인 / 진행 중 프로세스 / 다음 한 작업 / 필요한 결정:
- 변경분은 별도 기록하고 승인된 동작만 현재 명세에 통합한다.
