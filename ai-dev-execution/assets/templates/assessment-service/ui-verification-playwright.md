# UI Verification Preset — Assessment Service

visibility: internal_only

## Viewports

- mobile: 390x844
- tablet: Galaxy Tab class or 768x1024
- desktop: 1366x768

## Checks

- 학생 랜딩/코드 입력이 보이는가
- 문항 라디오/버튼 터치 영역이 충분한가
- 관리자 표가 가로 overflow 없이 읽히는가
- 한글 문장이 겹치거나 잘리지 않는가
- 오류/완료/결과 상태가 분리되어 있는가
