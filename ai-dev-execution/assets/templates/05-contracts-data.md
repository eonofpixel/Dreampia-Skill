## 5 G2 계약 확인

- [ ] UI·서버·저장소가 같은 필드·권한·상태 의미를 사용한다.
- [ ] 정상·거부·충돌·장애 응답을 구분했다.
- [ ] 재시도와 중복 요청이 무단 추가 부작용을 만들지 않는다.
- [ ] 실제 저장소의 제약과 경쟁 조건을 시험할 방법이 있다.
- [ ] 개인정보·보존·마이그레이션·이전 버전 영향을 검토했다.
- [ ] 적용하지 않는 항목의 이유와 남은 미지수를 기록했다.
