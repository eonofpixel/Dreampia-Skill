- 실제 구성요소: {{실제 DB·인증·API}} · 모의 구성요소: {{모의인 경계와 검증할 수 없는 범위}}

- 외부 연동: {{sandbox 여부·실제 발송/청구 방지·승인된 호출 비용 한도}}
- 재현 설정: {{런타임·잠금 파일·seed·시계·시간대·네트워크 조건}}
- 증거 보관: {{실제 저장 위치가 확인되기 전에는 미생성 / 접근 권한·보존 기간·비밀 마스킹 담당자}}
- 실행 순서: {{빠른 정적/단위 검사 → 계약·통합 → E2E·비기능 → 인수 검토의 실제 순서}}
- flaky 처리: {{불안정 원인 분류·재현 조건·격리 담당자·해제 기한}}. 재실행 중 한 번 통과한 것만 골라 최초 실패를 숨기지 않는다.

실제 백엔드에 접근할 수 없으면 핵심 E2E는 `NOT_RUN`으로 남긴다. 모의 E2E 결과는 별도 범위로 기록하고 실제 저장·권한 검증을 대체하지 않는다. 운영 데이터 사용·외부 전송·파괴적 정리는 필요한 승인 전 실행하지 않는다.

## 8 게이트 판정 준비

- [ ] G2: 요구→계약→작업→TEST 연결, 환경·데이터·실행 권한이 준비됐다.
- [ ] G3: 기능 검증 증거와 제품 인수 검토를 분리해서 기록했다.
- [ ] G4: 고정 릴리스 후보에서 회귀·비기능·staging 검증을 수행했다.
- [ ] 실패·미실행·연기 범위, 출시 차단 여부, 위험 수용권자를 숨김없이 기록했다.
- [ ] 실제 증거의 커밋·환경·시각·검증자가 대상 버전과 일치한다.
