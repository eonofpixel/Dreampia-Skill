# 0.5.0 독립 문서 사례 검토

검토 범위: 공통 스킬, 플랫폼 참조 4개, 실행/품질/팀 계약. 외부 도구·모델·소비 UI는 실행하지 않았다. 계획과 계약을 검토했으며 실제 제품 효과 시험이 아니다.

1. 웹: 한국어 검색·편집·저장, 기존 브랜드와 API, IME 조합, 응답 역전, 키보드 조작과 저장 후 재조회.
2. macOS: 다중 창 로컬 엔진 PoC, 창별 선택과 공유 작업 ID, 취소 요청과 확인된 종료, 창 닫기와 작업 취소 구별. 브라우저만으로 native 검증 PASS 금지.
3. React Native: iOS/Android 에뮬레이터, 키보드·safe area·배경 복귀·늦은 응답·초안 보존·중복 제출. 실제 기기 확인과 에뮬레이터 결과 구별.
4. CSV CLI: 인코딩/BOM/따옴표/오류/원자 출력/재파싱. GUI 없는 작업에 디자인 게이트나 원격 DB 강제 금지.

첫 검토 P2: 선택 하네스인데 팀 계약이 state.json/events.jsonl을 항상 요구함. 선택 사용 시에만 하네스 기록, 그 외 기존 프로젝트 증거로 수정.
첫 검토 P2: 실행 안내가 모든 작업에 화면/API/백엔드를 요구함. 실제 요청 경로와 실제 필요한 백엔드로 한정. 작은 변경의 문서·설계 규모도 §8의 선택 규칙과 맞춤.
사례 보완: 웹 IME/응답 역전, macOS 취소 확인/다중 창 경쟁, 모바일 늦은 응답/중복 제출 계약을 참조에 추가.

수정 범위 재검토 결과는 최종 외부 검증 영수증에 기록한다. 검토 반복 상한 2회. 소스 파일/링크 및 설치 전달 검증은 UI 접근성 적합성 또는 AI 효과의 증거가 아니다.

최종 수정 범위 read-only 재검토: 잔여 실질 결함 발견 없음. 선택 하네스/요청 경로/필수 백엔드 조건 및 웹 IME·응답 역전/macOS 창별 상태·취소 확인/모바일 늦은 응답·중복 제출 계약 일치. CSV는 GUI나 원격 DB 없이 입력→처리→출력 검증 가능. 실제 UI/엔진/API/CSV는 실행하지 않음.
